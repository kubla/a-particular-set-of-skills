# Accept text-only image briefs

An Image Upgrade Request may begin with a text-only Image Brief; an existing raster image or visual draft is not required. The requester-side skill is therefore named `request-image-generation`, a verb-object name that describes when an agent should invoke it without claiming the requesting product generates locally. Restricting requests to existing images would exclude the capability gap the system is meant to bridge, while names based on the schema role or abbreviated `image-gen` language would make model discovery less clear.
