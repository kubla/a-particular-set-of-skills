# Fulcra-backed Agent Skills

This context describes independently installable agent skills that project user-selected context into Fulcra, where the user controls its persistence and access.

## Language

**Context Projection**:
A user-authorized representation of context from another source in Fulcra. The projection can be retained and shared independently of the source system and the agents that consume it.

**Computer History Memory**:
A completed Markdown summary generated by Computer History from a bounded period of activity.
_Avoid_: Raw event, interaction event

**Source Folder**:
The validated local `resources` directory containing Computer History Memories. Setup discovers it from `$CODEX_HOME` or the standard `~/.codex` location and asks the user only when discovery fails.

**Context Collector**:
An owner-authorized program, integration, or agent role that acquires selected data from one or more sources and records it in the owner's context lake, preserving its provenance. A Context Collector creates or maintains a portion of the owner's Context Projection. The role is independent of its deployment topology and operational interface; Context Collectors need not share commands, scheduling, or interaction models.
_Avoid_: Gatherer, File sync

**Collector Manifest**:
A durable owner-controlled declaration of one configured Context Collector's intended behavior. It establishes expectations that agents can compare with observed catalog data; it is not a heartbeat or a claim that collection is currently working.

**Sweep**:
One deterministic, token-free collector run. A per-user macOS LaunchAgent starts a Sweep every ten minutes, while the same command remains available for manual recovery.

**Projection Status**:
The passive, locally recorded operational state of the Computer History projection, including recent Sweep outcomes and unresolved conditions requiring attention. It is queried on demand and reports observable facts; it is not a notification stream, and deeper investigation is diagnosis rather than status.

**Authentication Boundary**:
Fulcra authentication may prompt the user during setup, but a recurring collector Sweep never opens a browser or waits for input. An authentication failure preserves pending work and becomes an explicit failed Projection Status.

**Source Artifact**:
The unchanged Computer History Memory uploaded to Fulcra as a file at `Codex/<computer name>/memories/extensions/skysight/resources/<original filename>`. Its permissions are independent from those of any Projection Record derived from it.

**Codex Memory Namespace**:
The source-native Fulcra file hierarchy rooted at `Codex/<computer name>/memories/`. It preserves Codex's internal memory organization and can contain future memory-gathering projections beyond Computer History.

**Projection Record**:
One Fulcra duration annotation representing exactly one completed Computer History Memory. It contains the memory's current time range, projected Markdown with the source's terminal Citations section omitted, and provenance metadata, but no direct reference to its Source Artifact.
_Avoid_: Data row

**Projection Stream**:
An account-wide Fulcra duration-annotation data type containing Projection Records of one Summary Kind from all of the user's computers. The collector creates exactly two streams, named `Computer History (10-minute)` and `Computer History (6-hour)`, not separate streams for each computer.
_Avoid_: Per-computer data type

**Computer Identity**:
The computer's user-visible macOS name, preserved in the Projection Source. Computers with the same name intentionally share one identity.
_Avoid_: Installation ID, generated device ID

**Projection Source**:
The nested origin of a Projection Record: Computer History produced by Codex running on the named computer. This follows Fulcra's normal app-on-device source relationship.
_Avoid_: Contributing application

**Contributing Application**:
An application whose activity contributed to a Computer History Memory, as listed in the memory's metadata. Every listed application, including system helpers, becomes a human-readable tag on the Projection Record but is not part of the Projection Source; the original bundle identifier remains in the projected Markdown frontmatter and unchanged Source Artifact.

**Projection Interval**:
The time span represented by a Projection Record. It begins at the source filename's timestamp and ends at an explicit end time in the derived Markdown when available, otherwise at the nominal end implied by the Summary Kind; raw interaction events are never consulted.

**Projection Map**:
A recoverable local operational map connecting each Computer History Memory and its content hash to the Source Artifact and Projection Record created from it. It supports reliable projection without exposing that relationship through either independently permissioned Fulcra object.

**Revision**:
A content change to a still-present Computer History Memory. It creates a new snapshot of the existing Source Artifact and advances the existing Projection Record to the revised content rather than creating a second overlapping projection.

**Local Absence**:
The disappearance of a Computer History Memory from the local filesystem. It carries no deletion intent and never removes an existing Source Artifact or Projection Record from Fulcra.

**Summary Kind**:
The cadence of a Computer History Memory: ten-minute or six-hour.
